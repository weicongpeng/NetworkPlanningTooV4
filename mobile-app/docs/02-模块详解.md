# 模块详解

## 页面组件 (app/(tabs)/)

### index.tsx - 地图主屏

**职责**: 应用核心页面，整合地图渲染、扇区数据加载、图层管理、搜索、导航、打点、测量等功能。

**关键函数**:

| 函数 | 职责 |
|------|------|
| `initializeApp()` | 应用启动初始化：①初始化缓存系统 → ②从缓存加载扇区（优先）→ ③连接后端获取最新数据 → ④首次启动自动全量缓存 |
| `loadDataList()` | 加载图层数据列表，支持后端优先 + 缓存回退 |
| `handleTabLayerPress()` | 展开 TAB 图层子菜单 |
| `handleGeoDataPress()` | 展开地理化数据子菜单 |
| `loadMobileRenderData(dataId)` | 通过后端 API 加载渲染数据（TAB 图层或地理化数据），使用 WebView HTTP 加载避免 JS 注入大小限制 |
| `loadSectorsFromBackend()` | 从后端拉取 LTE/NR 扇区数据并写入 Zustand store |

**组件组合**:
- `SearchBar`: 搜索栏
- `LayerControl`: 图层控制
- `SectorInfoPanel`: 扇区信息面板
- `NavControl`: 导航控制
- `MarkerList`: 标记列表
- `MeasureControl`: 测量控制
- `NavigationPanel`: 导航面板

**状态来源**:
- 从 `useMapStore` 获取全局状态（扇区、标记、测量、导航等）
- 通过 `mapRef` 操作 `MapView` 组件（injectJavaScript）

### data.tsx - 数据管理页

**职责**: 管理三类本地缓存数据（全量工参、地理化数据、图层文件）的导入、刷新、下载、删除。

**关键函数**:

| 函数 | 职责 |
|------|------|
| `loadMeta()` | 从 `cacheService` 加载缓存元数据，更新 store 中的缓存状态 |
| `handleRefresh()` | 全量刷新：从后端重新缓存所有数据并刷新地图扇区 |
| `handleRefreshType(type)` | 按类型单独刷新（全量工参 / 地理化数据 / 图层文件） |
| `pickAndImportFile(type)` | 使用 SAF（StorageAccessFramework）选择本地文件并导入，支持多文件选择 |
| `startImport(fileUri, fileName, type)` | 执行实际导入，带进度回调和取消支持 |
| `reloadMapSectors()` | 导入后从缓存重新加载扇区数据到 store |
| `handleDownload(type)` | 导出缓存数据为文件并通过系统分享 |
| `handleDelete(type)` | 删除指定类型的缓存数据 |

**UI 结构**:
- 三类数据卡片（全量工参📡、地理化数据🗺️、图层文件📐）
- 每张卡片有刷新🔄、导入📥、下载、删除按钮
- 导入进度条 + 取消按钮
- 多文件导入时弹出选择对话框

### favorites.tsx - 收藏列表页

**职责**: 展示用户收藏的标记点列表，支持定位、导航、编辑名称、复制信息、删除操作。

**关键函数**:

| 函数 | 职责 |
|------|------|
| `handleDelete(id)` | 删除单个收藏点（带确认弹框） |
| `handleClearAll()` | 清空所有收藏（带确认弹框） |
| `handleNavigate(item)` | 设置 `pendingNavi` 状态并跳转到地图页，触发导航面板 |
| `handleLocation(item)` | WGS84 → GCJ02 坐标转换后定位到地图（设置 `focusLocation` + `searchMarker`） |
| `handleCopy(item)` | 复制收藏点信息（名称/坐标/时间）到剪贴板 |
| `handleEditPress(item)` / `handleConfirmEdit()` | 编辑收藏点名称（弹出 Modal 输入框） |

**状态来源**:
- 从 `useMapStore` 获取 `favorites`（持久化到 AsyncStorage）

**UI 结构**:
- 列表每项显示序号、名称、坐标、时间 + 5 个操作按钮（位置/导航/编辑/复制/删除）
- 空状态显示引导文案

## 核心组件 (src/components/)

**React 侧 Ref 方法（useImperativeHandle）**:

**导出的接口**:

**依赖关系**:

### coordinate.ts - 坐标转换

**职责**: WGS84 ↔ GCJ02（国测局/火星坐标）互转，中国境内偏移校正。

**核心函数**:

| 函数 | 职责 |
|------|------|
| `wgs84ToGcj02(lat, lng)` | WGS84 → GCJ02。中国境外直接返回原值；中国境内使用椭球体参数 + 正弦扰动算法计算偏移量 |
| `gcj02ToWgs84(lat, lng)` | GCJ02 → WGS84（迭代逼近法，5 次迭代，精度 < 1e-8） |
| `outOfChina(lat, lng)` | 判断坐标是否在中国境外（经度 72.004°-137.8347°, 纬度 0.8293°-55.8271°） |
| `transformLat()` / `transformLng()` | 经纬度偏移量计算内部辅助函数 |

**算法原理**:
- 基于克拉索夫斯基椭球体参数
- 偏心率平方: `0.00669342162296594323`
- 迭代逼近法逆向转换，5 次迭代精度 < 1e-8

### viewportFilter.ts - 视窗过滤

**职责**: 使用 RBush 空间索引快速筛选当前地图视窗内的点，避免渲染不可见数据。

**ViewportFilter 类方法**:

| 方法 | 职责 |
|------|------|
| `buildIndex(features)` | 从 GeoJSON 特征构建 R-Tree 空间索引 |
| `queryViewport(bounds)` | 查询视窗范围内的所有点 |
| `queryViewportWithLimit(bounds, maxResults)` | 带数量限制的查询，超出时自动均匀采样（默认上限 1000） |
| `countInViewport(bounds)` | 统计视窗内点数量 |

**ViewportBounds 接口**:
```typescript
interface ViewportBounds {
  west: number;   // 最小经度
  south: number;  // 最小纬度
  east: number;   // 最大经度
  north: number;  // 最大纬度
}
```

**导出**:
- `getViewportFilter()`: 获取全局单例
- `resetViewportFilter()`: 重建单例

## 模块间依赖关系总结

```
index.tsx (地图主屏)
  ├── cacheService → 缓存优先加载扇区
  ├── apiService → 后端拉取最新数据
  ├── useMapStore → 全局状态管理
  ├── MapView → AMap WebView 渲染
  │     ├── clusterManager → Supercluster 聚类
  │     └── viewportFilter → RBush 视窗筛选
  └── coordinate.ts → WGS84↔GCJ02 坐标转换

data.tsx (数据管理)
  ├── cacheService → 缓存导入/刷新/删除/导出
  └── reloadMapSectors() → 刷新 store 扇区数据

favorites.tsx (收藏)
  ├── useMapStore.favorites → 持久化收藏列表
  ├── coordinate.ts → 定位时坐标转换
  └── setPendingNavi → 触发导航

settings.tsx (设置)
  └── apiService → 地址配置 + 连接测试

config.ts (配置)
  ├── AsyncStorage → 用户自定义地址持久化
  ├── Constants → LAN IP 推导
  └── env → 环境变量
```
