# 工参地图 (gongcan-map) - 项目架构总览

## 项目简介

**工参地图**是一款基于 React Native (Expo SDK 52) 的 Android 移动应用，用于在地图上展示 LTE/NR 通信基站扇区数据。应用支持 GPS 导航、距离测量、收藏打点、离线缓存与本地文件导入等功能。

### 核心特性

- 🗺️ **地图渲染**: 基于高德地图 WebView 封装，支持 20000+ 基站扇区的聚类渲染
- 📡 **数据管理**: 支持后端 API 同步、本地 Excel/CSV/GeoJSON/MIF 文件导入
- 🧭 **GPS 导航**: 实时定位、路径规划、语音播报、偏航检测
- 💾 **离线缓存**: 首次启动自动缓存全量数据，支持手动刷新和导出
- 📍 **收藏打点**: 支持收藏位置点，持久化存储
- 📏 **距离测量**: 多点测量距离，Haversine 公式计算

## 架构分层

### 1. 路由层 (app/)

负责页面路由和导航结构。使用 React Navigation 的 Bottom Tabs 实现 4 个主页面。

**关键职责:**
- 页面组合和布局
- Tab 导航管理
- 页面间参数传递

### 2. 组件层 (src/components/)

可复用的 UI 组件，按功能模块组织。

**核心组件:**
- `MapView.tsx`: 封装高德地图 WebView，提供 26 个 ref 方法
- `NavigationPanel.tsx`: 导航 UI 面板，支持手势拖拽
- `SearchBar.tsx`: 搜索栏，支持扇区参数搜索和 POI 搜索
- `MarkerList.tsx`: 标记点列表
- `MeasureControl.tsx`: 距离测量控制

### 3. 服务层 (src/services/)

业务逻辑核心，封装后端 API 调用、缓存管理、导航引擎、数据解析等。

**核心服务:**
- `apiService`: axios 封装，动态 baseURL 解析
- `cacheService`: 本地文件缓存系统，首次启动自动缓存
- `navigationService`: GPS 定位 + 路径规划 + TTS 播报
- `dataParser` / `streamingParser` / `asyncParser`: 多格式文件解析

### 4. 状态层 (src/store/)

使用 Zustand 管理全局状态，仅 `favorites` 持久化到 AsyncStorage。

**状态分组:**
- 扇区数据: `lteSectors`, `nrSectors`
- 缓存状态: `cacheAvailable`, `cacheUpdatedAt`
- 标记/收藏: `markers`, `favorites`
- 测量: `measurePoints`, `measureMode`
- 导航: `isNavigating`, `gpsSignal`, `pendingNavi`
- 搜索: `searchMarker`, `focusLocation`

### 5. 工具层 (src/utils/)

纯函数工具，无副作用。

**核心工具:**
- `config.ts`: API 地址解析（优先级：用户自定义 > 环境变量 > LAN IP > localhost）
- `coordinate.ts`: WGS84 ↔ GCJ02 坐标转换
- `clusterManager.ts`: Supercluster 聚类管理
- `viewportFilter.ts`: RBush 空间索引视窗过滤

## 数据流核心路径

### 路径 1: 地图渲染

```
App 启动
  ↓
index.tsx (地图主屏)
  ↓
cacheService.getCachedSectors() → 优先读本地缓存
  ↓ (缓存不存在或需刷新)
apiService.getSectors() → 从后端下载
  ↓
cacheService.cacheFullParamsFromBackend() → 写入缓存
  ↓
useMapStore.setSectors(lte, nr) → 更新全局状态
  ↓
MapView.tsx → 接收扇区数据
  ↓
clusterManager.loadData() / viewportFilter.buildIndex() → 构建空间索引
  ↓
地图移动/缩放时:
  - clusterManager.getClusters(bounds, zoom) → 获取聚类
  - viewportFilter.queryViewport(bounds) → 获取视窗内的点
  ↓
injectJavaScript() → 调用 AMap API 渲染
```

### 路径 2: 本地文件导入

```
data.tsx (数据管理页)
  ↓
expo-document-picker → 选择文件
  ↓
cacheService.importFile(fileUri, fileName, onProgress)
  ↓
读取文件 (SAF / copyAsync / readAsStringAsync)
  ↓
判断文件大小:
  - >5MB: parseFileStreaming() → 流式解析
  - 1-5MB: parseFileAsync() → 异步解析
  - <1MB: parseImportedFile() → 同步解析
  ↓
解析过程:
  1. 检测表头行 (经纬度/方位角/名称字段)
  2. 逐行解析 + WGS84→GCJ02 转换
  3. 构建 GeoJsonFeature[]
  4. 定期 yieldToUI() 防 ANR
  ↓
写入缓存目录:
  - fullParams → sectors.json
  - geoData → geo_{id}.json
  ↓
更新元数据 (AsyncStorage @npt_cache_meta)
  ↓
useMapStore.setCacheAvailable(true) → 刷新 UI
```

### 路径 3: GPS 导航

```
NavigationPanel.tsx
  ↓
navigationService.planRoute(start, end)
  ↓
高德路径规划 API → 返回路线
  ↓
expo-location → 实时 GPS 定位 (WGS84)
  ↓
wgs84ToGcj02() → 转换为 GCJ02
  ↓
MapView.tsx → 渲染路线 + 当前位置
  ↓
expo-speech → TTS 播报导航指令
```

## 坐标系统

中国境内必须做 **WGS84 ↔ GCJ02 转换**:

- **WGS84**: GPS 标准坐标，后端返回的数据使用
- **GCJ02**: 国测局坐标（火星坐标），高德地图使用，在中国境内有偏移

**转换时机:**
1. 后端数据导入时立即转换
2. 本地文件导入时转换
3. GPS 定位后转换

**关键原则:** 所有进入地图渲染的坐标必须是 GCJ02

## 性能优化策略

### 1. 大数据量渲染

- **聚类**: 20000+ 点数据时使用 Supercluster 自动聚类
- **视窗过滤**: 使用 RBush 空间索引只渲染视窗内的点
- **数量限制**: 视窗内超过 1000 个点时自动均匀采样

### 2. 大文件处理

- **流式解析**: >5MB 或 >5000 行使用流式解析，分块读取
- **异步处理**: 中等文件使用 InteractionManager + 分片处理
- **让出主线程**: 每处理 50-100 行让出一次，防止 ANR

### 3. 缓存策略

- **首次启动自动缓存**: 下载全量数据到本地
- **优先读本地**: 启动时优先读缓存，后台刷新
- **增量更新**: 支持按类型单独刷新

## API 地址解析优先级

`src/utils/config.ts` 中 `getEffectiveApiBaseUrl()` 解析顺序:

1. 用户在 `settings.tsx` 自定义地址（AsyncStorage `@npt_custom_api_url`）
2. 环境变量 `EXPO_PUBLIC_API_URL`
3. 从 `Constants.expoConfig?.hostUri` 推导 LAN IP
4. 回退 `http://localhost:8000`

所有 API 路径会自动加 `/api/v1` 前缀。

## 关键约定

### 状态管理

- 全部使用 `useMapStore`（Zustand），不引入新状态库
- 只有 `favorites` 使用 `persist` + AsyncStorage 持久化
- 其他状态应用重启后清空

### 缓存目录

```
FileSystem.documentDirectory}cache/
├── fullParams/          # 全量工参
│   └── sectors.json
├── geoData/             # 地理化数据
│   └── geo_{id}.json
├── layers/              # 图层文件
│   └── layer_{fid}_{lid}.json
└── meta/                # 元数据（实际用 AsyncStorage）
```

新增缓存类型需在 `CACHE_DIRS` 注册。

### 服务单例

- `apiService` 和 `cacheService` 已导出单例，业务模块直接导入
- 不要重复实例化

### WebView 通信

- `MapView.tsx` 通过 `injectJavaScript` 调用 AMap API
- JS ↔ Native 使用约定的 `postMessage` 协议

### 响应式中文

- UI 文案为简体中文
- 保留原注释语言
